# Sum of 20 Numbers — C# Console App

In this project, the user enters **twenty numbers** and the program calculates and displays the sum of all the numbers.

## 🎯 Features
- Receive input from the user
- Validate and convert string to number
- Sum using loop

## 📌 How to run
1. Run the program 
2. Enter twenty numbers 
3. The sum is displayed

## 🧠 What you will learn from this project
- Working with `Console.ReadLine`
- Converting input to number with `int.Parse`
- Sum and loops
